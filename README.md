# ระบบเฝ้าระวังคุณภาพอากาศและฝุ่นละออง PM 2.5 โรงพยาบาลโพนสวรรค์

เว็บแอปพลิเคชันแดชบอร์ดรายงานสถานการณ์คุณภาพอากาศและฝุ่นละอองขนาดเล็ก (PM 2.5) สำหรับ **โรงพยาบาลโพนสวรรค์ จังหวัดนครพนม** ใช้ข้อมูลจริง 100% จาก **Air4Thai (กรมควบคุมมลพิษ)** และฐานข้อมูลจริงใน **Google Sheets** (ไม่มีข้อมูลปลอม/Mock Data)

## สถาปัตยกรรมระบบ
- **Frontend (`index.html`)**: Single-File Dashboard พัฒนาด้วย Tailwind CSS + Chart.js + ฟอนต์ภาษาไทย (`Prompt` / `Sarabun`) รองรับทั้ง Desktop และ Mobile
- **Backend (`Code.gs`)**: Google Apps Script Web App (`doGet(e)`) แก้ปัญหา CORS และ Mixed Content (HTTPS/HTTP) พร้อมฟังก์ชัน `fetchAndSaveAir4Thai()` ที่ตั้งเวลาบันทึกอัตโนมัติทุก 1 ชั่วโมง
- **Database (Google Sheets: `Phonsawan_Hospital_PM25_DB`)**:
  - ชีต `Hourly_Logs`: เก็บบันทึกค่า PM 2.5, AQI, PM10, NO2 รายชั่วโมงจริง (ป้องกันการบันทึกซ้ำ)
  - ชีต `Daily_Summary`: สรุปค่าเฉลี่ย ต่ำสุด สูงสุด และเวลาที่ฝุ่นสูงสุดประจำวันโดยอัตโนมัติ

## เกณฑ์มาตรฐาน PM 2.5 กรมควบคุมมลพิษ (5 ระดับ)
| ระดับ | สี | ค่า PM 2.5 (µg/m³) | ความหมาย |
| :---: | :---: | :---: | :--- |
| 1 | ฟ้า | 0 – 15.0 | คุณภาพอากาศดีมาก |
| 2 | เขียว | 15.1 – 25.0 | คุณภาพอากาศดี |
| 3 | เหลือง | 25.1 – 37.5 | ปานกลาง |
| 4 | ส้ม | 37.6 – 75.0 | เริ่มมีผลกระทบต่อสุขภาพ |
| 5 | แดง | มากกว่า 75.0 | มีผลกระทบต่อสุขภาพ |
